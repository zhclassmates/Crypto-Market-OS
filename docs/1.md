====================
八、重点验证“钱包数”
====================

这一项单独做。

我要最终知道：

GMGN 当前数据源能不能直接实现：

每天活跃钱包数
每天独立买家
每天独立卖家
每天新增钱包
每天持有人数

分别给结论：

DIRECT
DERIVABLE
SNAPSHOT-ONLY
NOT AVAILABLE

定义：

DIRECT
= GMGN 已直接返回对应历史值

DERIVABLE
= GMGN 给了逐笔交易/钱包地址，可以自行聚合

SNAPSHOT-ONLY
= 只能从现在开始每天保存当前值，无法从 GMGN 直接恢复完整历史

NOT AVAILABLE
= 当前 GMGN 数据无法得到

这里尤其不要犯：

buys=unique_buyers
sells=unique_sellers

这种错误。

必须拿 raw JSON 证明。
